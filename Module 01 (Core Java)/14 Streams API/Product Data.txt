---------------

Here are 10 progressively challenging use cases based on your `Product` class. They force students to think about **filter**, **map**, **sorted**, **distinct**, **limit**, **skip**, **reduce**, **collect**, **groupingBy**, and **counting**.

---

## 1. Find Available Products

Display all products that are currently in stock.

**Hint:** `filter()`

**Expected Output**

```
Laptop
Smartphone
Mechanical Keyboard
...
```

---

## 2. Premium Products

Display names of products whose price is greater than ₹10,000.

**Hint:** `filter()`, `map()`

**Expected Output**

```
Laptop
Smartphone
Monitor
```

---

## 3. Product Names in Uppercase

Display all product names in uppercase.

**Hint:** `map()`

**Expected Output**

```
LAPTOP
SMARTPHONE
WIRELESS MOUSE
...
```

---

## 4. Sort by Price

Display all products sorted by price in ascending order.

**Hint:** `sorted(Comparator.comparing())`

**Expected Output**

```
Wireless Mouse
USB-C Charger
Gaming Headset
...
Laptop
```

---

## 5. Top 3 Most Expensive Products

Find the three most expensive products.

**Hint**

```
sorted(descending)
limit(3)
```

---

## 6. Products Purchased After March 2026

Display products purchased after `2026-03-31`.

**Hint**

```
filter(product -> product.getPurchaseDate().isAfter(...))
```

---

## 7. Total Inventory Value

Calculate the total inventory value.

Formula:

```
price × quantity
```

Example

```
65999.99 × 15
+
28999.50 × 30
+
...
```

**Hint**

```
map()
reduce()
```

---

## 8. Average Price of Available Products

Find the average price of products that are currently available.

**Hint**

```
filter()
mapToDouble()
average()
```

---

## 9. Products Having More Than Two Variants

Display names of products having more than two variants.

Example

```
Laptop
Mechanical Keyboard
Monitor
```

**Hint**

```
filter(p -> p.getVariants().length > 2)
map(Product::getName)
```

---

## 10. Group Products by Stock Status

Create a `Map<Boolean, List<Product>>`.

Output should conceptually look like

```
true
    Laptop
    Monitor
    Smart Watch
    ...

false
    Wireless Mouse
    USB-C Charger
    Gaming Headset
```

**Hint**

```
Collectors.groupingBy(Product::isInStock)
```
